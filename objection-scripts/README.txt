OBJECTION SCRIPTS FOLDER
========================
Drop your objection handling scripts here. Supported formats: .docx, .pdf, .txt

The sales AI agent will reference these when generating word-for-word responses
for reps on live calls.

Naming convention suggestions:
  - price-objection.txt
  - maintenance-fee-objection.txt
  - not-interested-objection.txt
  - need-to-think-about-it.txt
  - spouse-not-here.txt
  - already-have-enough-points.txt

Files added here will be available for the AI to incorporate into its scripts.
